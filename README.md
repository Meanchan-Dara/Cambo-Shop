# React + TypeScript + Vite
Frontend of Content Production Project

## Tech Stack
```
- React
- TypeScript
- Vite
- Tailwind CSS
```

## Run Project
- Install dependency:
```bash
npm install
```

- Run project:
```bash
npm run dev
```

## System Pattern
```
- src/
  - assets/       <- images, icons, svg, etc
  - components/   <- components (reusable components)
  - contexts/     <- context for react (context provider, etc)
  - hooks/        <- custom hook (useQuery, etc)
  - layout/       <- layout (header, sidebar, footer, etc)
  - page/         <- page (component for each page)
  - services/     <- api services (axios instance, api calls, etc)
  - schemas/      <- zod schema (schema for validation)
  - utils/        <- utils (common functions)
  - App.tsx       <- main app component
  - main.tsx      <- entry point
```
